# StudyFlow — Study Timetable Planner

A responsive weekly study timetable planner built with HTML, CSS, and JavaScript.

## Features
- Add a subject, day, time, and topic or activity
- View study sessions grouped by weekday
- Automatically sort sessions by time
- Delete individual sessions
- Clear the complete timetable
- Save timetable data in browser local storage
- Responsive layout for desktop and mobile

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter a subject, choose a day and time, and optionally add a topic.
4. Select **Add to timetable**.

No installation or API key is required.

## Privacy note
Timetable entries are stored in local storage in the browser on the device where they are entered. They are not synced to an account or stored in GitHub. Clearing browser data may remove them.
